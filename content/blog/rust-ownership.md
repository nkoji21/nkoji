## move が「コピー」ではないこと

C++98 だと代入はコピーだから、代入後も元の変数はそのまま使える。Rust は違って、所有権が移動して元の変数は無効になる。頭では分かっても、手が覚えているのは前者だった。

```rust
let s1 = String::from("hello");
let s2 = s1;
println!("{}", s1); // error: borrow of moved value
```

### 借用チェッカとの付き合い方

可変参照は同時に1つだけ、という規則は C の `restrict` に近い発想だと考えると入りやすかった。データ競合を型で防いでいる、という理解に繋げると並行処理の章が一気に楽になる。

> コンパイラのエラーメッセージを読むのが一番の教材だった。
